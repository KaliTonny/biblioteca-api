# Biblioteca API

## Objetivo
Gerenciar livros e empréstimos de uma biblioteca.

## Integrantes
- Etony Guedes
- Geovanna Almeida


## Entidades
- Livros
- Empréstimos

## Endpoints

### Livros
GET /livros
GET /livros/:id
POST /livros
PUT /livros/:id
DELETE /livros/:id

### Empréstimos
GET /emprestimos
POST /emprestimos
DELETE /emprestimos/:id
